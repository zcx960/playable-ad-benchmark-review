可玩广告对标评审速查清单

一、证据范围
[ ] 两版使用相同视口、方向和内容阶段
[ ] 记录实际验证到哪一步
[ ] 实测值、代码核对值、建议值分开
[ ] 未验证项明确写出

二、首屏与视觉
[ ] 自有品牌、CTA、货币、角色、首个目标清晰可见
[ ] 功能设备的缺料/运行/暂停/满仓状态可辨认
[ ] 角色、设备、地面在色相和明度上分离
[ ] 接触阴影、UI 层级、安全区无问题

三、首次操作
[ ] 首次输入前有文案/手势/摇杆/箭头
[ ] 首次有效操作后教程及时切换
[ ] 角色能到达目标，不会持续顶墙

四、核心因果链
[ ] 输入有即时反馈
[ ] 资源有生成、落地、吸附、计数过程
[ ] 携带实体、容量和实际交付一致
[ ] 生产投入、启动、运行和暂停原因可见
[ ] 交付进度、容器状态和奖励同步
[ ] 奖励到账后立即出现下一目标
[ ] 解锁物件立即产生行为或效率变化

五、每条核心反馈
[ ] 位置/现状具体
[ ] 竞品参考对应同一阶段
[ ] 修改包含对象、触发、状态、数值和切换规则
[ ] 验收标准可观察、可复现、可计数

六、交付前
[ ] P0/P1/P2 分级合理
[ ] 有 30—60 秒节奏表
[ ] 有最终验收清单
[ ] 无虚构实测、无空泛建议、无直接复制竞品资产
